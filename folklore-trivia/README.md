# Russian Folklore Trivia

A 15-question quiz on Russian folklore and Pushkin's fairy tales, in English and Russian.

## Play it

**Online:** https://avelaxonov.github.io/script-vault/folklore-trivia/

Nothing to install. Works on phones and laptops.

**Offline:** download [`russian-folklore-trivia.html`](russian-folklore-trivia.html) and double-click it. The whole app is one file, no internet needed after that.

## What's in here

| File | What it is |
| --- | --- |
| `index.html` | The quiz, served as the web page for this folder |
| `russian-folklore-trivia.html` | Identical copy, meant for downloading and running offline |
| `matlab/AvelinasFolkloreTrivia.m` | The original MATLAB version this was built from |

## Running the MATLAB version

Open `matlab/AvelinasFolkloreTrivia.m` in MATLAB and run it. It plays in the command window: type the letter of your answer and press Enter.

## Setup note

The link above works once GitHub Pages is on: **Settings → Pages → Deploy from a branch → `main` → `/ (root)`**. Give it about a minute after saving.
