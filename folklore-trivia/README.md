# Russian Folklore Trivia

A 15-question quiz on Russian folklore and Pushkin's fairy tales, in English and Russian.

**Online:** avelaxonov.github.io/script-vault/folklore-trivia/

**Offline:** download [`russian-folklore-trivia.html`](russian-folklore-trivia.html) and double-click it. The whole app is one file, no internet needed after that.

## What's in here

| File | What it is |
| --- | --- |
| `index.html` | The quiz, served as the web page for this folder |
| `russian-folklore-trivia.html` | Identical copy, meant for downloading and running offline |
| `AvelinasFolkloreTrivia.m` | The original MATLAB version this was built from |

## Running the MATLAB version

Open `AvelinasFolkloreTrivia.m` in MATLAB and run it. It plays in the command window: type the letter of your answer and press Enter.
